# Dishaa Bhat | Personal Portfolio

My personal portfolio site, where I share my projects, technical skills, and a bit about who I am as a Computer Science student at George Mason University.

**🔗 Live site:** https://dishaabhat08.github.io/01-prj-personal-site/

## About

This is a single-page website I designed and built to be the home for my work. It introduces me, lists the technologies I work with, and links to my projects so visitors can view the live sites or the code. As I finish more coursework and personal projects, I'll add them here.

## Sections

- **About:** who I am and how my creative background in dance and digital art shapes the way I approach technology
- **Skills:** the languages and tools I work with, including Python, Java, C/C++, web development, TensorFlow, and OpenCV
- **Projects:** project cards with short descriptions and links to each live site and its code
- **Contact:** email, LinkedIn, and GitHub links

## Features

- **Responsive design:** the layout adapts from desktop to mobile
- **Custom design system:** colors defined as CSS variables, with a soft purple palette and a mix of serif and sans-serif fonts
- **Accessible markup:** semantic HTML sections, labeled navigation, and `aria` attributes
- **Smooth in-page navigation:** header links jump to each section

## Built With

- HTML5
- CSS3 (Flexbox, CSS custom properties, media queries)
- Hosted on GitHub Pages
